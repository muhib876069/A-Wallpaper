# ✨ Features

<br>🎨 VS Code Inspired Design: Dark theme with syntax-highlighted colors

📊 Real-time Updates: Live time, date, and day progress percentage

💻 Developer Friendly: Displays time data in a code object format

🖥️ Full Screen Mode: Immersive experience (configurable)

⏰ Day Progress Tracker: Visual percentage of how much day has passed

🎯 Easy to Close: Prominent exit button

# ⚙️ Installation

git clone https://github.com/muhib876069/code-style-clock.git
